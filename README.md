# UHT Hub Website

Simple Vite + React + Tailwind site for UHT Hub — a technology training and coworking centre.

Run locally:

```bash
npm install
npm run dev
```

Publishing slides and pitch deck

1. Place the original PPTX file in the `public/` folder as `UHT_HUB_Pitch_Deck.pptx`.
2. Export slide images (JPEG/PNG) and place them in `public/slides/` as `slide-1.jpg`, `slide-2.jpg`, etc.
3. The site will show a "Pitch Deck & Slides" gallery on the homepage and provide a download link for the PPTX.

If you want, I can extract text and images from the PPTX for you — upload the untruncated PPTX file here or allow me to access it and I'll convert slide content into site copy and images.
